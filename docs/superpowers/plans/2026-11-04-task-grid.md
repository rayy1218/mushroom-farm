# Tasks as a grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Tasks tab shows the room's daily tasks as a week grid (days × tasks, ticks and initials) that workers tick from, with Undo and a printable month sheet.

**Architecture:** No new read endpoint: the page pivots `GET /api/calendar` (past, today's closed rows, planned days) and `GET /api/rooms/:id/tasks` (today's open rows with ids) into a grid with pure helpers in `web/task-grid-math.js`. The server gains `POST /api/tasks/:id/undo`. The grid is its own module (`web/task-grid.js`) mounted by the Tasks card in place of its day list and Log; the month sheet is a print page (`web/task-sheet.js`) like the myGAP sheet.

**Tech Stack:** Node 22 (`node:http`, `node:sqlite`, `node --test`), plain JS modules, no build step, no dependencies.

Spec: `docs/superpowers/specs/2026-11-04-task-grid-design.md` (read it first). Branch `feat/task-grid`, worktree `.claude/worktrees/task-grid`. `npm test` (2132 pass at the start). Commit as the repo's configured user; never push. Never touch `data/v2.db` or ports 8080/8090–8094 (the live farm). Follow the repo's conventions (short plain comments saying what and why; tables in docs; DESIGN.md's named rules; pages are plain DOM modules with destroy/unmount; tests with `node:test`).

## File map

| File | Responsibility |
|---|---|
| `server/db.js` | `undoTask(id, { since })`: reopen a daily row closed at or after `since` and delete its harvests, one transaction |
| `server/tasks.js` | `undo(id)`: the 60 s rule, the 409 texts, events (tasks; harvest when harvests went) |
| `server/tasks-api.js` | `POST /api/tasks/:id/undo` (the existing TASK_ACTION route gains 'undo') |
| `web/task-grid-math.js` (new) | Pure: `weekOf`, `monthOf`, `gridColumns`, `gridCells`, `initialsFor`, `SHORT_NAMES`/`shortName`, `boxWords`, `sheetRows` |
| `web/task-grid.js` (new) | The grid: desk/phone layouts, tap, long-press menu, details, keyboard, week navigation |
| `web/tasks-card.js` | Mount the grid in place of the day list and the Log; keep Upkeep, Long-term and the CSV link |
| `web/task-dialogs.js` | Reuse Done/Skip dialogs; an Undo call |
| `web/task-sheet.js` (new) | The month print page |
| `web/route.js`, `web/app.js` | `?week=` on the Tasks tab; `#/rooms/:id/tasks/sheet?month=` |
| `web/styles.css` | `.tg-*` grid and `.ts-*` sheet styles, print rules |
| `DESIGN.md`, `README.md` | The grid component note, the routes |

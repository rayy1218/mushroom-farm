# Lion's mane (Hericium erinaceus): research synthesis for C8

Owner decision 2026-10-09 (lead decision 57): the app uses a lion's mane pinning CO₂ limit of 1000 ppm, not the 700 proposed in section 6 below (700 gave a 450 ppm purge stop level and a too-wet pinning room on the C9 air exchange; 1000 is inside the 500–1100 range of the sources, S13).

## 1. Scope and method

| Item | Value |
|---|---|
| Input | `docs/research/2026-10-08-lionsmane-equipment-raw-findings.json`, sweeps `academic` (32), `growers` (93), `tropical` (104) |
| Extra web work | One search and two page reads on 2026-10-08 for the rest stage, the only stage with no source at all (sources S14 rest text, S30) |
| Unit rule | °F converted to °C first: °C = (°F − 32) × 5 / 9, one decimal (55 °F = 12.8, 60 = 15.6, 65 = 18.3, 68 = 20.0, 70 = 21.1, 72 = 22.2, 74 = 23.3, 75 = 23.9, 78 = 25.6, 80 = 26.7, 85 = 29.4, 95 = 35.0) |
| One source | One publisher (domain). Several pages of one publisher count once (the publisher's widest band). The Out-Grow warm-weather strain counts apart from the Out-Grow standard strain (a different strain). Pages that only repeat the Stamets table (S2's citation, S12's primordia figures) are not counted twice. |
| Median | Median of each source's band midpoint (a single value is its own midpoint) |
| Range | Lowest band end to highest band end over all sources |
| Confidence | high: 8 or more sources and most bands overlap; medium: 3 to 7 sources, or many sources with wide spread; low: 1 or 2 sources, unverified pages, or generic (not lion's mane) data |
| Tropical sources | S2 (Thai strains), S3, S9, S10 (Thailand), S4 (India), S31 (SE Asia); S25 is a Japanese grower blog (not tropical) |

## 6. Proposed crop profile

| Check | Rule in the code | Result for the profile |
|---|---|---|
| AC setpoint range | `MACHINES.acSetMin 16`, `acSetMax 30` (controller.js), sim clamps 16–30 | All T targets 16–23 °C |
| Wet pass rule | `PASS.wetRH 95`, `wetMax 10` % of the day (capacity.js); band `BANDS.RH 3` | Fruiting 90 (band edge 93), pinning 92 (band edge 95, the same as today's oyster pinning) |
| Low RH alarm | `rhLo` at target − 8 | Fruiting 82, pinning 84 |
| Temperature alarms | `tLo` at target − 2; `tCrop` outside `limits` | Pinning 16 − 2 = 14 = `tMin` |
| Mixed rooms | `commonTargets` needs overlapping `range` | `T [16, 22]` overlaps black oyster `[21, 25]` at 21–22 only; no overlap with the other seven crops |
| Cold shock | `shock.T` is raised to 16 and raises `shockLimit` | Pinning already sits at 16, so no `shock` flag |
| Comment at controller.js line 44 | "Only crops that fruit near tropical room temperature (a split AC cannot hold 16-21 °C on a 33 °C day)" | Lion's mane breaks this rule; C8 has to change the comment and the room needs a bigger AC or insulation (see equipment-facts.md section 8) |

```js
    // Cool crop (fruits at 16-22 °C): needs an insulated room and a larger AC than the tropical crops.
    // CO2 sets the shape: above about 1000 ppm long spines and coral shapes. Pick at 6-12 mm spines, before yellowing.
    lionsmane: { name: "Lion's mane",
      spawn:    [23,   // spawn T: median 22.5 °C of 20 sources (18-27), rounded up (lower AC load)
                 80,   // spawn RH: S4 spawn room 80-85 %; in-bag values (S1 95-100, S25 90-95) do not apply to sealed bags
                 5000],// spawn CO2: Stamets lower bound (S1 5000-40000), the same as every other crop
      pinning:  [16,   // pinning T: median 15.5 °C (10-24), raised to the AC minimum 16; S3 farm pins at 16
                 92,   // pinning RH: sources 90-100 (median 97.5); 92 + band 3 = 95 = PASS.wetRH
                 700], // pinning CO2: top of the 500-700 ppm band of S1, S12, S15, S22 (median 600; 700 keeps fanOff at 450)
      fruiting: [20,   // fruiting T: median 19.5 °C of 22 sources; 19 of 22 bands contain 20; S11 says above 20 limits
                 90,   // fruiting RH: median 90 % of 19 sources (85-95 in 13); 90 + band 3 = 93, below PASS.wetRH 95
                 1000],// fruiting CO2: median ceiling 1000 ppm of 10 sources (800-1100)
      rest:     [21,   // rest T: S14 rests the block in colonisation conditions 18-24 °C (midpoint 21)
                 80,   // rest RH: no source; the house value of every crop
                 2000],// rest CO2: no source; the house value of every crop (S30 asks for fresh air)
      limits: { tMin: 14,    // S14: below 14 °C pins abort; also pinning 16 minus the 2 °C alarm band
                tMax: 27,    // S13 warm strain fruits to 27; S6 incubation not above 26.7; S28 fruited at 26.7
                coreMax: 30 }, // below the 32 °C mycelium collapse (S4), above the 27 °C working core (S25)
      coreTarget: 25,        // mycelium growth optimum 25 °C (S8, S2, S4)
      range: { T: [16, 22],  // median lower end 16, median upper end 21.6 of the 22 fruiting-T bands
               RH: [85, 92] } }, // median lower end 85; upper end 95 cut to 92 by the wet rule (92 + 3 = 95)
```

| Flag | Proposed | Why |
|---|---|---|
| `shock` | not set | Pinning target is already the AC minimum (16 °C); no supplier requires a refrigerated shock (growers sweep note 6); S13 warm strain needs none |
| `spawnLights` | not set | Only S3 uses light in spawn run; S1, S24, S26 dark |
| `maxFog` | not set | No source in the findings says lion's mane must not get direct fog; worth one check before C8 is frozen |
| `noFogBoost` | not set | No source |
| `casing` | not set | No source mentions casing for lion's mane |
